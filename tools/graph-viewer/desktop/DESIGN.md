# WithHuman Viewer: 앱 설계

`index.html`(브라우저용 페이지, `server.py`가 띄움)을 Dioxus 데스크톱 앱으로 새로 만든다.
외부 사용자에게 배포한다. UI와 로직은 Rust로 쓰고, 그래프 그리기만 당분간 Cytoscape(JS)에 맡긴다.

## 기존 페이지의 기능 목록

| 영역 | 기능 | 새 앱 |
|---|---|---|
| 세션 선택 | 검색(프롬프트·의도·폴더·ID), 폴더 필터, "차단·확인 있는 세션만", 날짜별 묶음, 고정, 삭제(10분 내 활동 세션은 거부), 키보드 이동 | 왼쪽 사이드바로 상시 표시 |
| 그래프 | SubGraph 영역, 노드 종류별 색, Call 테두리는 판정 색, 흐름선, 원인선(¶문단 · 확률) | 그대로. 레이아웃 계산은 Rust |
| 보기 | 원인 트리 / 시간 흐름, 전체 보기, 자동 갱신(3초), 범례 | 그래프 위 도구 막대 |
| 선택 | Call을 누르면 원인 사슬 강조, 원인선을 누르면 원인 문단과 Jev 질의 | 그대로 |
| 상세 패널 | 판정(결정·규칙·이탈 점수·Jev 시간), 원인(연결·비율 막대·부모·원인 결과 미리보기), 이탈 게이지, 2차 확인, Jev 질의 기록, 문단(숨김·원인 테두리), 토큰, 속성 | 오른쪽 인스펙터, 탭으로 나눔 |
| 조건 비교 | 케이스 검색, 조건 칩(이름 붙이기), 케이스×조건 표, 정탐·미탐·오탐 집계, Call을 누르면 그래프로 | 별도 화면(후반 단계) |
| 기타 | 패널 폭 조절·기억, 고정 세션·조건 이름은 브라우저 저장소 | 앱 설정 파일에 저장 |

## 화면 구성

```
┌──────────────────────────────────────────────────────────────────────┐
│ WithHuman Viewer   [그래프|비교]                  ● 데모 데이터  ⚙   │
├───────────────┬──────────────────────────────────────┬───────────────┤
│ 🔍 검색        │ [원인 트리|시간 흐름] [전체 보기] ⟳ 자동 │ #7 Call       │
│ [폴더▾] ☐차단만 │                                      │ [판정|원인|문단│
│               │        (그래프 캔버스)                 │  |속성]        │
│ 오늘           │                                      │               │
│ ▸ payments… 🔴 │                                      │               │
│   outdated…   │                                      │               │
│ 어제           │ 요청 의도 메시지 결과 ALLOW DENY 원인    │               │
└───────────────┴──────────────────────────────────────┴───────────────┘
```

- 상단 바 하나: 화면 전환, 데이터 출처 배지(누르면 설정), 설정 버튼.
- 연결 실패, 세션 없음, 세션 미선택은 빨간 글씨가 아니라 안내 카드로 보여 준다
  (예: "Neo4j에 연결할 수 없습니다 · [설정 열기] [데모 보기]").
- 설정은 시트(모달). 첫 실행에는 "Neo4j 연결 / 데모로 둘러보기"를 고르게 한다.

## 구조

- `api.rs`, `graph.rs`, `settings.rs`, `demo.rs`: 데이터. UI는 이 함수를 직접 부른다(HTTP·`viewer://` 없음).
- `model.rs`: API 응답을 타입이 있는 구조체로 바꾼다.
- `layout.rs`: 원인 트리·시간 흐름 배치와 원인 사슬. 페이지의 `build`, `arrange`, `treeElements`,
  `flowElements`, `chainOf`를 옮긴 것으로, 목업으로 단위 테스트한다.
- `ui/`: 컴포넌트. 그래프 캔버스는 Cytoscape를 띄운 JS 섬이고, Rust가 위치가 정해진 요소를 보내면
  그리기만 하며, 누른 노드·엣지를 Rust로 돌려준다. 배치가 Rust에 있으니 나중에 SVG로 바꾸기 쉽다.

## 단계

1. 골격: 사이드바, 그래프, 인스펙터(판정·원인·문단·속성), 안내 카드, 설정 시트. iframe과 `index.html` 의존 제거.
2. 마감: 메뉴·단축키(⌘R, ⌘,, ⌘F, ⌘1/⌘2), 창 상태·마지막 세션 기억, 삭제 확인 네이티브 다이얼로그, 키체인에 비밀번호.
3. 조건 비교 화면, 인스펙터의 이탈 게이지·2차 확인·Jev 기록.
4. 배포: cargo-packager로 서명·공증된 .dmg, cargo-packager-updater, CI.
